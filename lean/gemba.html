Outil Lean #01

GEMBA

WALK

"Le vrai lieu, la vraie chose." Aller là où la valeur est réellement créée pour observer les processus factuels.

1
Quitter son bureau

Les vrais problèmes se résolvent sur le terrain (atelier, chantier), pas dans une salle de réunion.

2
Observer, ne pas juger

L'objectif est d'identifier les gaspillages (Muda) réels, sans pointer du doigt les opérateurs.

3
Écouter les équipes

Poser des questions ouvertes. Ceux qui font le travail sont ceux qui connaissent les meilleures solutions.
